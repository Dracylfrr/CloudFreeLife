# UI assets

The interface is drawn with CSS and inline SVG, so there are no bitmap UI assets to ship.

- Icons: [`src/ui/Icon.svelte`](../../src/ui/Icon.svelte) (one stroke-based SVG path per icon).
- Logo / app identity: [`../icons/cloud-freelife.svg`](../icons/cloud-freelife.svg) (a soft cloud, a paintbrush and a pastel paint mark) and [`src/ui/Logo.svelte`](../../src/ui/Logo.svelte).
- Font: Nunito (`src/assets/nunito-latin.woff2`, SIL Open Font License).
- Pastel palette tokens: [`src/app.css`](../../src/app.css).
