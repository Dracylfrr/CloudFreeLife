# Contributing

Thanks for helping keep Cloud-Freelife gentle. A few ground rules:

## Principles
1. **Calm first.** Soft colors, slow motion, no harsh sounds, no pressure mechanics (timers, scores that punish, locked content).
2. **Offline-first and private.** No telemetry, accounts or tracking. Network use is limited to GitHub release checks and user-requested downloads.
3. **Light.** Avoid new dependencies, constant timers and large textures. Animation must be stoppable (Reduced Motion, Low Power, window hidden).
4. **Never lose art.** Anything that touches saving must be tested.
5. **Content is data.** Books, pages, palettes and levels are manifests + SVG, never hard-coded in components.

## Getting started
```powershell
npm install
npm run dev        # browser preview (uses browser storage)
npm run tauri dev  # desktop app
npm test && npm run check
```

## Pull requests
- Keep changes focused; add or update tests in `tests/` (Vitest).
- Run `npm test`, `npm run check` and `npm run build` — all must pass.
- UI changes: test at 980 × 660 (the minimum window) and with *Reduced Motion* on. Add a line to [docs/QA_CHECKLIST.md](docs/QA_CHECKLIST.md) if you add a feature.
- Add an entry to [CHANGELOG.md](CHANGELOG.md).

## Adding content
Content contributions are very welcome — see [docs/CREATING_BOOKS.md](docs/CREATING_BOOKS.md), [docs/CREATING_PAGES.md](docs/CREATING_PAGES.md) and [docs/CREATING_LEVELS.md](docs/CREATING_LEVELS.md). All artwork must be **original** (or properly licensed and credited). No copyrighted characters.

The bundled content in `content/` is generated by `scripts/generate-content.mjs` from the scenes in `scripts/art/`. You can edit either the generator or the resulting files, but do not mix both for the same page — regeneration overwrites `content/`.

## Code style
TypeScript strict mode, small modules, no giant files. Svelte 5 runes. Prefer plain functions in `core/` that are easy to unit test.
